# Comments Summarization

Этот проект предназначен для суммаризации комментариев с использованием модели T5-трансформера от Hugging Face. 

## Описание

В основе решения лежит T5-трансформер, обученный для суммаризации чатов. Используется модель [ru_t5_chat_sum](https://huggingface.co/Hacker1337/ru_t5_chat_sum), которая была дообучена на небольшом количестве данных на протяжении нескольких эпох.

Для определения отношения комментария к посту используется косинусная близость очищенных и лемматизированных текстов. Пороги определены как:
- **Комментарии к посту**: 0.2
- **Комментарии по теме**: 0.04

## Установка

Для развертывания и запуска проекта используется Docker. 

## Файлы

- `solution.py`: основной файл для запуска программы.
- `requirements.txt`: зависимости Python, необходимые для работы проекта.
- `Dockerfile`: файл для сборки Docker-образа.
- `dataset.jsonl`: датасет с постами и комментариями.

## Использование
Скрипт принимает три параметра:
1. Режим ("all_comments" - обрабатывает все комментарии, любой другой - отфильтровывает не относящиеся к посту комментарии;
2. Исходный файл (`dataset.jsonl`);
3. Результат (тоже jsonl).

### Запуск в докере
- docker build -t my_nlp_app .
  
для Windows:

- docker run -v %cd%:/app my_nlp_app all_comments dataset.jsonl result.jsonl
  
для Linux:

- docker run -v $(pwd):/app my_nlp_app all_comments dataset.jsonl result.jsonl


## Зависимости

Все зависимости описаны в `requirements.txt` и будут установлены автоматически в процессе сборки Docker-образа.
